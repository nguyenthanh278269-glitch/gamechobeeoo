⚡ 3 Thể Động Từ To Be

Điểm 0
📌 Cấu trúc 3 Thể Động Từ TO BE:
• (+) Khẳng định: S + To Be (am/is/are/was/were...)
• (-) Phủ định: S + To Be + NOT (is not = isn't, was not = wasn't, are not = aren't...)
• (?) Nghi vấn: To Be + S ...? (Trả lời: Yes, S + To Be / No, S + To Be + not)
